# My_Gamepad

Das Gamepad basiert auf dem Pico RP2350 Plus von Waveshare. Für den RP2350 sprechen neben dem schnellen Prozessor, der USB-C Anschluss und das Batteriemanagement. Eine eigens dafür entwickelte Platine vereint den Pico, ein 2 Zoll LCD Display, das SD-Karten Modul und 8 Bedientaster. Zusätzlich ist der Boot-Taster als externer Taster nach außen verlegt. Das hat seinen Grund in der kompakten Bauweise. Der originale Taster ist unter dem Display sehr schlecht zugänglich. Wenn Sie das Gamepad nachbauen wollen gebe ich hier das Platinenlayout (erstellt mit KiCad) an. In der Zip-Datei befinden sich alle erforderlichen Gerber- und Drilldateien. Laden Sie diese einfach bei einem geeigneten Hersteller hoch.

Für mein Gamepad habe ich einen Bootloader entwickelt, der die Spieleanwendungen von SD-Karte in den Flashspeicher kopiert und von dort startet.

Nachfolgend finden Sie hier einige der Spiele, die auf dem Gamepad laufen. Sie wurden speziell für die Nutzung mit dem Bootloader entwickelt.
